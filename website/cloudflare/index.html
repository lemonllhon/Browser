云端同步授权

这张实例图，展示的是“设备已经被云端认可”。

用户授权后，控制台会记录同步服务、授权账号、当前设备、设备 ID、绑定 ID 和最后心跳。它不是装饰信息，而是判断备份、恢复、分享是否可信的状态页。

服务地址确认同步入口 授权账号确认数据归属 设备与绑定 ID 确认当前机器 最后心跳确认在线状态
